# Atelier 3 : concevoir un cours avec l'IA

<div class="key">
**Objectif :** passer d'un thème à une séance structurée.
</div>

## Étape 1 : objectifs pédagogiques et plan de séance

Définissez les objectifs pédagogiques de la séance.
Demandez un plan de séance avant d'écrire les supports.

## Étape 2 : itérer

Il est beaucoup plus facile d'itérer sur un plan de séance que sur des supports.
Itérer sur le plan est donc plus efficace qu'une fois les supports terminés.

## Étape 3 : supports

- **Diapositives** pour les cours magistraux
- **Page interactive** pour comprendre visuellement
- **Exercices pratiques** pour les séances de pratique
- **Quiz** pour évaluer les étudiants

Un support avancé ou complexe ne prend pas plus de temps à créer.

## Étape 4 : itérer

Itérez jusqu'à ce que les supports soient de qualité satisfaisante.

<div class="warn">

**Vous êtes l'auteur.** L'IA peut se tromper sur une dose ou inventer un protocole : vérifiez chaque fait avant de l'enseigner.

</div>
